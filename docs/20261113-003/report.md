# 六场比分约束后处理实验 · 20261113-003

先在 FTT 实现算法与实验，固定结果后再导入 RallyMark。六场共 121 个 GT 回合、592 秒阳性时段；数据集与旧实验相同。GT 仅在评估脚本使用。视频未重新渲染，结果是原片时间标记。

## 算法

1. 按置信度取 Top-N TAD，合并重叠或相接区间，与 OCR 融合并以 OCR 为结束时间。
2. 孤立 TAD 的最短时长与邻域过滤保留；高排名候选可免邻域过滤，避免漏检。
3. 对可信 OCR 的合法逐分变化建立比分锚点。相近 TAD 碎片先并入相邻比分回合；两个锚点间没有未解释的得分时，丢弃剩余候选。
4. 开头在限定窗口内用已知比分约束候选数，优先有 TAD 支持的候选；不把首次出现比分反推的 0:0 时间当作真实锚点。尾部只有可靠终局且无后续重置证据时才剔除额外候选。
5. OCR 缺失、比分矛盾、可能换局时保留不确定候选；只有唯一解才补比分。无可靠比分则不启用比分剔除。

领先两分终局支持 10 平之后的加分。规则依据 [ITTF 2026 官方规则入口](https://db.ittf.com/document/389) 与 [USATT 规则](https://www.usatt.org/rules-of-table-tennis)。原 OCR 错把大于 11 的数字丢弃，此处已修复。

## 数据与消融

TAD 复用六场已保存的各 200 个候选，不改模型、权重或 NMS。早田、陈熠两场重新提取全部 2 FPS 裁剪帧，并在本机 CPU 跑完整 RapidOCR；其余四场复用无加分的原始逐帧 OCR 观测后重新计算状态。两场重跑分别耗时 497.85 / 418.05 秒。未申请 GPU。

同一批新像素观测模拟旧版“最多 11 分”的代码，两场仍各只能产生 22 个 OCR 回合；修复后各 24 个，排除了仅由运行平台变化造成新增终局的解释。新环境 Python 3.11、NumPy 1.26.4、RapidOCR 1.4.4、ONNX Runtime 1.20.1，与旧推理平台不同，其他 OCR 边界可能存在小幅漂移。模型文件 SHA-256 与依赖清单均本地留存。

## 多轮搜索与选择

- 第一轮：72 组，搜索碎片合并距离 0–3 秒、比分置信度 0.5/0.8/0.95、首尾证据窗口 0/30/60 秒。
- 第二轮：1,367 组新增配置，联合搜索 Top-N 30–200、邻域 1–30 秒、保护排名 0–200、孤立最短时长 0–1 秒。
- 第三轮：10,214 组新增配置，在候选最佳区间细化 Top-N、保护排名、邻域、碎片间隔和最短时长。

共 11,653 组不同配置，搜索耗时 314.33 秒。完整 CSV 在 `results/20261113-003/search/`。优先尝试零已覆盖 GT 时段损失及各视频 FN 不增加，再按完全漏检、覆盖不足一半、IoU≥0.3 FN、IoU≥0.5 FN、F1、时间 F1 排序。

没有配置同时满足“每场 IoU≥0.5 FN 均不增加”：陈熠最后一球 GT 为 489–491 秒，旧 TAD 为 488.489–492.371（IoU 0.515），新增 OCR 为 487.75–492.25（IoU 0.444）。这是 2 秒 GT 对 4.5 秒 OCR 固定回溯窗口的边界失配；GT 仍完全覆盖。最终配置已覆盖 GT 秒数损失为 0，整体 FN 更低。未为迎合该 GT 缩短 OCR 固定窗口。

## 结果

回合级使用最大二分匹配，避免贪心重复占用；IoU≥0.5 的 TP/FP/FN 对边界也敏感。时间级指标对区间并集计算，不重复计时。GT 为人工整秒近似标注，无额外容差。Micro 合并计数，Macro 为六场等权平均。

## 泛化与保留

六场均用于开发与选择参数，这不是独立测试集。summary.json 提供逐场指标、参数与留一场诊断；留一场只用五场指标排序，但候选网格的细化参考过全体数据，因此不能当无偏泛化估计。新转播布局、跨局完整比赛、OCR 跳分、重播、擦网重发等需另建验证集。比分规则约束的是计分回合，无法据此保证每个实际击球片段都属于假阳性。

旧、新原始输出、逐帧 OCR 观测、六份 metadata、全部网格、配置、源码快照、指纹及依赖保存在本地 results/20261113-003；视频由 dataset.json 的字节数和 SHA-256 绑定。模型与视频不进入 Git。更新产品前应验证 FTT 和产品适配器逐条区间及比分一致。

## 正确性题库与性能验收

固定题库已扩展为 42 份人工期望的 JSON 样例，另有独立小状态胜方序列穷举、200 个固定种子的完整比分插入假片段场景、10,000 个加分位置推断与来源守恒检查，35 个测试方法通过。见 [题目与数据范围](https://github.com/Momoyeyu/ftt-demo/blob/c836c83bbbfa0327a25f6cb6077cafa83bb69f10/docs/score-postprocess-problem.md)。这些测试发现并修复了隐藏换局证据被忽略、终局后推断不可能比分等问题；修正后已重新跑完三轮 11,653 组搜索，推荐参数和六场指标保持上述结果。
