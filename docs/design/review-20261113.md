## Acceptance

- 320, 390, 768, 1024, 1440 and 1920px: no horizontal page overflow. Selector/settings baselines match; cards remain inside their grid. Desktop video/control surfaces share top and bottom edges.
- Expanded controls: long titles, 12 options, low-height viewport, independent menu scroll, typeahead, arrows, End, Escape, outside dismissal and returned focus.
- Dialogs: Tab and Shift+Tab containment, dismissal, hidden underlying file inputs, confirmation/cancel focus, stable page gutters.
- Playback: one-click navigation, automatic skipping, manual seeking, keyboard endpoints, final-page selection, empty markers and Chromium landscape fullscreen with an exit control.
- Touch emulation: play, tap-to-seek, custom file action/chooser, restored metadata, 44px targets and reduced motion.
- Product states: initial upload, upload progress, queued analysis, failure/retry, empty analysis, empty history and disconnected API.
- Fonts are bundled locally. Native form controls remain only as hidden/transparent semantic inputs; no visible OS selector, file widget, progress bar or browser title tooltip is used.
- Production build continues to exclude the local importer, local-review styles and experiment-data endpoint.

Validation: `make check`, `make test`, 21 web unit tests and 6 maintained Playwright scenarios pass. Three local PostgreSQL-dependent tests are skipped; the existing GitLab CI supplies PostgreSQL. No GPU or model change is involved.
