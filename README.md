# RallyCut

乒乓球比赛视频自动剪辑平台。上传比赛原片，识别有效回合，生成便于复盘的精简视频。

## 基本思想

- 保留从发球到回合结束的有效内容，减少等待、擦汗、暂停等无效时间。
- 通过结构化时间区间连接分析结果与剪辑流程，支持结果回看和质量评估。
- 前端以移动端适配为高优先级，同时支持桌面端使用。
- 采用 monorepo 管理前端、业务后端和算法服务，各部分可以独立部署。

## 项目组成

- 前端负责视频提交、任务进度与剪辑结果展示。
- 后端负责面向用户的 API、任务管理及业务逻辑，通过内部 API 调用算法服务。
- 算法服务封装 GPU 推理能力，支持独立部署与后续扩容。

## 算法来源

现阶段采用 FTT dual-adapter TAD 与比分 OCR 实验 demo 作为后续开发依据。该 demo 包含实验代码、模型权重和样例数据，由算法侧独立维护。产品项目后续按需复用和封装其中的实现，保留来源与版本记录。

[ModelScope 实验 demo](https://www.modelscope.ai/models/yubodata/ftt-dual-adapter-tad-ocr-15raw)
